# 默认分享设计：全幅主题阅读卡

设计标识：`full-bleed-reading-v1`。提炼自《第一财经》2026年10月刊已确认的分享组图；这里只保存可复用的视觉规则，不附私人样张、阅读原话、账号或本机路径。换书时重新选句和构思底图，不沿用该期内容。用户自定风格优先。

## 视觉与组图

| 项目 | 默认规则 |
| --- | --- |
| 画幅 | 竖版3:4，交付1080×1440 PNG；这是设计默认值，不是平台永久规格。原生生成尺寸不同，使用可用工具等比导出并检查字形，不能拉伸或截掉出处。 |
| 背景 | 与本卡主题相符的摄影感/写实主题示意图，铺满整个画布直达四边。没有中央图块外框、外圈纯色、悬浮纸卡或不透明文字框。 |
| 气质 | 温暖米色、低饱和灰与深墨色为系列基调，真实材质与自然光；按题材变化场景，整组色调协调。 |
| 层级 | 安静页眉（书刊/版本）、可选页码 → 主体大字 → 底部具体篇目。文字距四边约7%—9%；这是文字安全区，背景仍须满版。 |
| 主体 | 一卡一个读者感想、金句、问题或关键信息。依语义换行与重点改变字号，文字和场景共同占据画面；正文结束后不空出大片无用途区域。 |
| 字体 | 按主题、语气、句长、底图选字形、笔触与字重。可用现代宋体气质、人文衬线或克制的手写感；不锁定同一款，不一律手写，不随机堆字体。 |
| 出处 | 内容卡底部显示实际文章/章节标题。封面可写实际书刊名；跨篇内容列全相关篇目或拆卡。出处不能被主体、裁切或装饰遮挡。 |
| 不展示 | “读者原话/观点整理”等分类、“读这篇时的感想”、记录ID、无必要主题小标题、英文副标题、额外口号、虚构封面与标志。 |

一般为一张封面加若干内容卡，张数由有据可用的内容决定。六个独立观点可以是七图；材料少则少做，长句拆卡，不强凑七张。封面标题可以提炼，但不能伪装成原文引句。

背景主体放在能与文字相互避让的位置；例如消费主题可用无品牌食品静物，产业主题可用抽象生产空间，阅读封面可用书桌与光影。不得把生成背景说成文中真实门店、企业或现场。优先靠构图与自然明暗保证对比，避免用厚蒙版遮住主体。

## 制作方式

默认使用宿主实际可用的图片生成能力，**一张图一次生成背景、文字与完整排版**。先读取可用专业设计 Skill 的相关规则，按 [设计接入](share-design-adapters.md) 用于视觉规划；默认设计已经确定，不再要求用户重新挑字体、设计 Skill 或填写参数。工具由宿主发现，不捆绑某一家生成服务、API密钥或付费配置。

默认方向本身已是用户选择；无须为每张重新索取样式确认。需安装依赖、付费授权或缺失参考图时，遵守宿主相应要求。没有可用生图能力时先交付锁定文案和制作说明，标记图片待制作；不能把实验HTML模板当成此设计已经完成。用户要求可编辑文字时，可采用实际可用字体精确排版，保留同一设计方向。

一次生成的文字仍可能出错。逐张看图核对每个字、标点、限定词、页眉、页码与出处；错误只修对应图并复核。同一张连续两次修正仍不合格，停止生成式重试；有现成精确排字能力时说明实际方式、只修该张并重新核验，否则交付其余合格图与该张待修状态。错字图不纳入可上传成品，部分合格不称整组完成。工具或用户已有更严格额度时以其为准。

将以下内容替换为已核文案与本卡构图；不要把占位符原样交给生成器。整组复用视觉约束，各卡重新指定场景和字体方向。

> 生成一张完整竖版3:4中文阅读分享卡，背景、全部中文与版式一次生成。主题示意背景覆盖整张画布和四边，无中央图片外框、外圈底色、悬浮纸卡或厚蒙版。温暖米色、低饱和灰与深墨色协调，材质自然。场景：{本卡主题场景、主体位置与文字区域}。字体：{根据本句主题、语气和长度选择的字形与节奏}，保持手机阅读清楚；与本组其他图协调但不机械复用同一种字体。主体文字按语义换行，仅改变排版，逐字保留以下内容与标点：{锁定正文}。小页眉：{书刊及版本}；页码：{序号/总数，若使用}；底部篇目：{已核标题}。文字距边缘约7%—9%，背景仍满版。只呈现指定文字，不添加分类、英文副标题、记录号、口号、标志或水印。读者观点不冒充出版物原句。示意图不冒充真实现场。

风格参考图仅在用户已授权且宿主能取得时使用。它用于色调、层级和气质参考，不锁定字体，不复制私人文字。没有参考图时，这份规则仍可独立使用。
