# 来源、接力与完成

## 来源归档

为实际收到的来源保留 ID、标题、作者/发布者、平台、URL 或原文件名、可确认日期、版本、可见范围、定位和归档状态。不要把未提供的文件记成上传失败。一个附件可以关联多个记录，笔记中必须能找到其真实存储指向。

PDF、EPUB、图片及其他非大型音视频附件默认保留原格式、原始字节；解压、OCR、转录等仅作衍生材料，不能替代原件。先确认工具实际能取得原文件；文件名、聊天预览或文件检索结果不必然是可上传字节。无法取得时标待归档，仍可保存用户思考。

截图先直接视觉查看，区分正文、图注、批注与界面。OCR 仅在必要时辅助，标明未辨清部分。连续图片按内容核对重叠与顺序，不凭上传次序猜正文。保存全部收到的阅读原图，用户明确说不保存时除外。

网页和公众号保留原 URL，合法可访问且能力允许时保存网站原下载文件或 HTML/PDF 等快照。网页快照和提取文本均标明副本类型及覆盖范围；不把标题摘要冒充完整网页。只保存 URL 就说“仅保存链接”；需要快照但失败时另标“快照待归档”。不绕过登录、付费或访问限制。

视频与播客默认不保存大型媒体本体，记录链接、创作者、时长和时间码；实际可取得的字幕、转录可作为轻量附件保存，保留原扩展名。只有字幕时，不声称已核查画面或语气；自动转录的含混字词不静默改成确定引文。

成功以实际写入及可用的回读/元数据/哈希校验为依据。笔记、原附件、快照、链接状态分别报告。已写入但未能核验时标“保存待核验”，不是假装失败也不是宣称成功。

## 精确定位与载体切换

以对象、版本、章节/小节、独特短句或图表及上下文作为内容定位；辅助坐标分别记录纸书印刷页、PDF 文件页序、PDF 印刷页、阅读器页码/位置及进度百分比。不要用电子百分比乘纸书总页数换算，也不要把不同版本的图号或页码直接混同。

确切对应才标已匹配；有多个候选标待核对；没有线索标待定位。仅仅主题相同不能证明同一段落。定位未知不阻碍先归档和记录，歧义会导致错误归属时才询问最小线索。

分开保存用户确认的已读进度、最近讨论位置、当前设备显示位置。补拍早期章节不倒退整体进度，跳到后文截图也不表示此前全读完。版本/平台百分比不直接比较。

## 会话接力

用户要求或会话变长影响可靠性时，在当前回合核对并保存未落盘记录，再生成接力摘要。摘要至少含：阅读库及对象 ID、配置入口、主档定位符、最后记录/来源 ID、用户确认进度、最近讨论位置、当前判断与重要变化、未解问题、附件状态、下一步。

接力信息是执行状态，不是新增感受。接力文件写入后更新索引指向，回读确认。不要在摘要中写令牌、秘密或完整原文。无法保存则交付待保存摘要并说明，不宣称下一会话必然自动恢复。

用户自行创建新聊天时，给一段可复制的接力启动语，包含对象名和可安全提供的配置入口。新会话先读配置和索引，再主档和最新接力；旧摘要不能覆盖后来的正式记录。多对象无法从入口区分时只问对象，不凭 Memory 猜。

## 阅读完成与个人汇总

确认完成范围：一章/一篇子来源完成，不自动标记整本书、整期或整个专题完成。用户明确整本读完时更新状态，但汇总覆盖度仍以真实笔记为准。

生成读后感前读取该范围全部正式记录。内容长时按文件顺序分段读取并记录已检查范围，再做整体综合；无法完整访问时明确覆盖的记录范围和缺口，不说全量汇总。用户从未写下的感受不能借网上书评补齐。

产物包含适用的阅读轨迹、用户认知变化、最终赞同/存疑/反对、跨来源关联、未解问题与个人读后感。每项关键归纳能对应记录 ID；必要时把证据映射放文末而不打碎正文。不编个人评分，不虚构“读完后很震撼”等情绪。

读后感保留用户声音，AI 的新增思考独立放置。原始主档保留，汇总文件明确标记为衍生产物并登记回原对象。用户只要求一份汇总，不机械创建六份重复报告。汇总后的修改仍以用户最新明确要求及原始证据为准。

## 故障处理

权限失败不改为公开路径；格式转换失败不伪装扩展名；索引写入失败不谎报主档也失败，应分别说明并保留可修复的真实位置。发现并发冲突、主档重复或失效链接时停止破坏性覆盖，核对真实状态再处理。不承诺后台补档。
