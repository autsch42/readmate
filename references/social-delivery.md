# 分享预览 → 社交平台草稿

默认平台是小红书，默认动作是**保存草稿**。这两个默认值即可运行，不要求用户填写平台名、账号ID、Cookie、API密钥、浏览器端口或配置文件。登录仍由用户在宿主支持的官方环境中完成；Readmate 不内置账号，也不保证每个宿主都具有上传能力。

## 从报告到发送

| 阶段 | 触发与动作 | 完成依据 |
| --- | --- | --- |
| 报告 | 完成交付后按入口主动询问是否制作分享内容 | 已交报告；尚未同意则不出图、不上传 |
| 制作 | 用户同意，按默认设计出图并提供标题、正文、话题 | 图片逐张核对，配文可复制，源记录留在私有区 |
| 预览 | 会话内展示可点开图片、整组顺序和完整文案 | 用户能看到将要上传的实际版本；标明下一步“保存到小红书草稿箱” |
| 发送 | 用户在预览后说“保存到小红书草稿箱”“一键发送”或“发到小红书” | 使用当前用户的授权登录态上传，默认存草稿；不用重复问已明确的授权 |
| 核验 | 查草稿列表并重新打开相同草稿 | 标题、全部图片及顺序、正文、话题、AI声明等与批准版本相符，记录实际定位 |

“生成分享图文”只授权制作。“还是可以的/不错”只表示对内容反馈，不等于上传指令。用户要求正式公开发布时，明确识别为不同动作，遵守宿主发布权限；默认流程不代点正式发布或定时确认。用户一开始已明确指定“做好后存草稿”，先展示实际预览，再按已有授权继续，不再要求批准同一动作。

## 工具与登录：自动发现，不绑定账号

1. 检查宿主实际可用的小红书连接器、专用上传 Skill 或已获授权的浏览器工具。能完成任务的专用能力优先；读取其入口、权限与当前能力，执行它要求的查重、并发保护和保存封装。不把某台机器的 Jarvis 路径、固定浏览器、端口或历史标签页ID当作所有用户的依赖，也不绕过宿主工具边界。
2. 在将执行上传的同一工具/浏览器环境中检查登录态，读取当前账号的可见身份。用户明确指定自己的账号且当前仅有一个已授权账号时直接使用；存在多个候选或指定账号与当前账号不符时，只澄清账号选择。默认绝不从原阅读文件或历史回执猜账号。
3. 没有登录时引导用户打开该工具提供的官方登录入口完成登录，然后在同一环境复查；不索取密码、验证码或Cookie文本，不导出登录态，不将凭据写到任何笔记、配置或日志。用户完成登录后继续原任务，不再次索取上传许可。
4. 没有合适上传能力时仍完整交付图片和文案，说明“未上传”，提供手动导入步骤。不得把只在本机可用的工具当作通用内置能力，或为追求“一键”静默安装脚本、浏览器与插件。

“一键”表示预览后一句指令即可调用现有能力，不代表绕过首次登录、宿主权限或平台校验。其他社交平台按用户指令切换，沿用制作/预览/授权/核验步骤；没有适配能力就交付材料，不假称已适配。

## 上传与核验

- 只上传批准版本的最终PNG和文案。按清单顺序上传，首图即封面；不上传阅读主档、来源附件、提示词、证据和私有清单。上传前核实文件存在、可读、张数与实际版本，不能把预览HTML当PNG。
- 在同一平台环境查重：比对已有回执、草稿标题、封面/图组和正文。已存在且相符就返回既有草稿；返回超时或结果不确定时先查询、再决定是否重试，不盲目新建第二份。空列表或平台校验异常依实际上传工具的规则处理，不把错误当作空箱。
- 核对当前登录账号，填写标题、正文与相关话题；如工具支持真实话题选择，检查实际绑定。AI生成背景或文字排版应在平台填写相应AI声明，配文保留主题示意图说明。原创声明涉及平台承诺或协议时遵守宿主规则，不替用户同意；缺少可选声明可保留草稿并报告，不虚报已勾选。
- 保存动作使用上传工具的正式草稿能力。保存后查看列表，再打开同一草稿核对图数、顺序、文字与必要设置。逐字段报告实际状态；保存返回成功但未能回读时写“草稿保存待核验”，不宣称已发布。正式发布与定时保持未开启。
- 记录草稿真实ID或定位、实际标题、保存时间（可取得时）、工具与浏览器范围、核验结果，进入该分享包的私有上传回执，并关联原阅读对象。公开包中不放账号昵称/ID、登录二维码、Cookie、token、浏览器profile、本地绝对路径或草稿截图中的私人信息。

## 结果回报

明确区分“图文已生成”“草稿已核验”“公开已发布”。默认仅能到前两项，不把草稿叫作正式发表。

小红书网页草稿可能只存在执行浏览器的本地存储。以当前平台提示和工具回读为准；若是本地草稿，必须说明实际浏览器/应用名称与可执行的查看路径，例如“打开本次保存所用浏览器 → 小红书创作平台 → 草稿箱 → 图文笔记”，并明确日常其他浏览器和手机App不会自动出现。不能只给一个创作平台首页链接让用户误以为草稿已云端同步，也不能复制开发者个人电脑的应用路径给其他用户。

上传失败时保留可用图片和文案，说明卡在哪一步；授权或登录不足就停在该步，不换账号、不公开链接、不转投其他平台。重新执行前核对是否已经保存，避免重复。
