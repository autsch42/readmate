# 阅读伴侣 / Readmate

> 让 AI 陪你长期阅读，保存你的思维变化，而不只是生成摘要。

Readmate 是一个帮助你快速记录阅读过程中想法的Skill。当你在进行阅读时，无论是纸书、电子书还是网页文字，你都可以通过拍照/截图/分享链接/语音的形式将你看到的内容和你的思考让这个skill 帮你整理、延展信息和归档；读完后，再基于真实记录生成属于你的内容阅读汇总。

我们的愿景是：**让每一次阅读留下的不只是书摘，而是你如何理解、怀疑、联想和改变看法的过程。**

当前为 **v0.1.0 早期试用版**，安装这个skill，然后开启对话即可。

几个示例：

场景一：阅读一本杂志，不同的文章引发了你的思考，拍照对应片段后使用这个skill，告诉模型你的想法，这个Skill自动帮您记录并整理，多个文章的不同记录可以汇总为对杂志的阅读记录。

场景二：阅读一本纸书，看到不同章节想要记录片段，拍照后使用这个Skill，哪怕读到后面切换为电子书继续读，也可以直接截图/拍照，在告诉模型具体哪本书之后，帮你自动汇总到同一篇读书笔记。

场景三：阅读一篇公众号文章/小红书热帖，截图后使用这个Skill，告诉模型你的想法，自动整理查询对应信息，帮你梳理碎片化的思路，完善讨论和思考。

安装方法：

对话框输入这条指令即可：请根据 https://skillhub.cn/install/skillhub.md，安装 @indiv-imqianxun/readmate。

## 功能与优点

- **边读边聊，不用填表。** 支持书籍、杂志、公众号、网页、PDF、论文，以及视频和播客的可获取内容。
- **保留你的声音。** 区分原文、你的即时感受、整理后的个人观点与 AI 延伸，不把 AI 的结论冒充你的判断，并保留前后观点变化。
- **连接不同来源。** 围绕同一问题组织专题阅读，比较不同来源的支持、冲突与补充，而不是堆积孤立摘要。
- **档案和设置写进文件。** 默认使用 Markdown，格式与路径可随时调整；明确的长期偏好及时保存，新会话重新读取，不靠模型记忆。
- **阅读可以接力。** 通过笔记、索引与接力摘要恢复进度；读完后生成个人读后感、认知变化和待追踪问题。

## 安装与开始使用

按所用平台的 [安装指南](INSTALL.md) 安装完整 `readmate` 目录，保留 `SKILL.md` 和配套资源，不要只复制入口文件。

安装后，调用 Readmate 并说：

> 开始记录《书名》。先告诉我笔记的保存格式和实际保存位置。

首次运行默认使用 **Markdown（`.md`）和宿主已确认的默认持久保存位置**，不强制绑定云盘。你可以随时说“以后保存到这个目录”“修改笔记格式”“不用记”或“准备接力”。更改格式须有相应工具支持；临时导出不会改变默认设置，调整默认值也不会擅自迁移旧笔记。

## 使用注意事项

**保存以实际结果为准。** 文件读取、网页访问、格式转换和附件归档依赖宿主工具及授权。每次保存应分别报告成功、失败、待归档或仅保存链接，临时沙箱不能冒充长期阅读库。

**附件保留原格式。** PDF、截图、EPUB 等保存原件并关联笔记；网页尽量保留可恢复副本。大型音视频原文件默认不下载，只记录链接、时间码及可取得的字幕或转录。

**保护隐私，保留独立判断。** 私人笔记、配置与凭据不要放进公开仓库或 Skill 安装目录。跨 Agent 接力需要新环境能访问或导入原档案，不是自动同步；AI 分析可能出错，重要事实请核对原始来源。
